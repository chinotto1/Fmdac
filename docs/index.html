FM-1

Install Fmdac.

Fmdac 0.2 loads with this page. Connect one FM-1 with a USB data cable, in Chrome or Edge on a computer. Leave the cable in until the page says the FM-1 came back.

The screen opens on parameters. The page buttons open FX, HOME, SEQ, EDIT, ARP, LFO, ENV, and GLO. K1–K4 change the values. PLAY starts a 16-step drum pattern, and the keys play a tone. The converter colors the FM-1's own mix on the way to the headphones. It does not run on audio coming from the computer. Installing replaces the firmware that is on the FM-1.

If it stops

Finish or recover

The screen says UPDATE, or it stays dark after a write has started: plug the FM-1 in, connect, and choose the same package. This page finishes an update only with the matching file.

The FM-1 does not start: switch it off, hold OCT−, and switch it on. The screen says USB RESCUE. Install again from this page.

Windows shows a disk named WL80UBOOT and no MIDI port. That is the chip's own boot mode, and this page has no way to speak to it. From a computer, use FM-1-transporter.
